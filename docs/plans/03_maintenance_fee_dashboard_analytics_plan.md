# 통계 대시보드(다중 차트 및 다각도 분석) 구현 계획서

## 1. 목표
사용자가 제공한 이미지와 같이, 단순한 목록 조회를 넘어 **'수입/지출(관리비) 월별 추이'**, **'항목별 비중'**, **'호수별 누적액'** 등을 한눈에 파악할 수 있는 다각도 분석 대시보드를 구축합니다.

## 2. 화면 구성 (새로운 통계 탭 또는 대시보드 화면 상단)
기존의 단순 '일괄 업로드' 영역 위에 넓은 공간을 확보하여 4~5개의 차트 위젯을 그리드(Grid) 형태로 배치합니다.

### 📊 차트 구성안 (Chart.js 활용)
1. **월별 총액 추이 (막대그래프 - Grouped Bar)**
   - X축: 청구 연월 (예: 26년 3월, 4월, 5월...)
   - Y축: 총 청구 금액
   - 범례: 호수 (1403호 vs 2001호 막대가 나란히 서 있어서 월별 변동을 한눈에 비교)

2. **항목별 비중 (도넛 차트 - Doughnut)**
   - 전체 청구액 중 '건물관리용역비', '수도요금', '전기요금' 등이 각각 몇 %를 차지하는지 원형으로 시각화.
   - 클릭 시 특정 호수나 특정 월 기준으로 필터링 연동.

3. **호수별 누적 관리비 비중 (도넛 차트 또는 누적 막대)**
   - 등록된 전체 기간(3~7월) 동안 1403호와 2001호가 납부한 총액 비율 비교.

4. **단일 항목 집중 분석 (꺾은선 그래프 - Line)**
   - 사용자가 '전기개별' 이나 '수도개별' 처럼 특정 세부 항목을 콤보박스에서 선택하면, 그 항목만의 월별 변동 금액을 꺾은선으로 보여주는 심화 분석 차트.

5. **🚨 요금 이상 급등 알림 (Anomaly Detection 위젯)**
   - 자바스크립트가 자동으로 각 호수의 전월 데이터와 이번 달 데이터를 비교합니다.
   - 총액이나 특정 세부 항목(예: 전기요금, 수도요금)이 전월 대비 **일정 비율(예: 20% 이상) 또는 일정 금액 이상 크게 뛰었을 경우**, 붉은색 알람 카드(또는 배지)로 "2001호 7월 전기개별 요금이 전월 대비 35% 급등했습니다!" 라고 콕 집어서 경고해 줍니다.

## 3. UI/UX 디자인 (제니트리 v5.0 기준)
- 화면 상단에 기간 필터(예: `2026.03 ~ 2026.07`)를 두어 전체 차트가 동시에 움직이도록 연동.
- 각 차트는 하얀색 카드(`jt-card`) 패널 안에 들어가며, 마우스를 올렸을 때 정확한 금액 툴팁이 예쁘게 표시됨.
- 색상 테마: 사용자가 올려주신 레퍼런스 이미지처럼 산뜻하고 구분하기 쉬운 다중 색상 팔레트 적용.

## 4. 데이터 연동 로직
- `app.js`에서 Supabase 데이터를 한 번 불러오면(캐싱), 자바스크립트가 데이터를 **월별, 호수별, 항목별**로 3차원 분해 및 재조립(Pivot)하여 각각의 Chart.js 인스턴스에 데이터를 주입합니다.

## 5. 진행 단계
1. **대시보드 UI 확장**: `index.html`의 [대시보드] 화면 레이아웃을 다중 차트가 들어갈 수 있게 CSS Grid로 분할.
2. **데이터 가공 로직 구현**: 불러온 데이터를 월별 통계, 항목별 통계로 변환하는 헬퍼 함수 작성.
3. **Chart.js 연동 및 렌더링**: 4가지 종류의 차트를 화면에 그리기.
4. **글로벌 필터(기간/호수) 연동**: 필터를 바꿀 때마다 4개의 차트가 동시에 애니메이션과 함께 업데이트되도록 구현.
