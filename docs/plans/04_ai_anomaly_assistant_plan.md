# 04_ai_anomaly_assistant_plan

## 1. 목표 (Goal)
- 사용자가 [AI 이상 감지] 탭에서 표시된 알림 내역(급등, 신규 청구 등)에 대해 제미나이(Gemini) AI에게 직접 질문하고 답변을 받을 수 있는 'AI 비서' 기능 구현.
- 브라우저나 소스 코드에 API 키를 노출하지 않고, 클라우드플레어(Cloudflare Pages Functions) 내부 서버를 활용하여 완벽한 보안 유지.

## 2. 사용자 검토 필요 (User Review Required)
> [!IMPORTANT]
> **API 키 설정 위치**
> 실제 서비스 배포 후, 클라우드플레어 대시보드의 **[설정] > [환경 변수]** 메뉴에서 `GEMINI_API_KEY`라는 이름으로 제니 님의 실제 제미나이 API 키를 입력해 주셔야만 서버가 작동합니다. 이 부분은 코딩이 끝난 후 제가 다시 상세히 안내해 드리겠습니다.

> [!NOTE]
> **커스텀 모달(팝업) 디자인**
> 브라우저 기본 경고창(`alert` 등) 대신, 현재 앱 디자인과 어울리는 자체 팝업 모달창을 만들어 대화형(채팅) UI로 제공할 예정입니다.

## 3. 변경 예정 사항 (Proposed Changes)

### 3.1. 프론트엔드 (UI 및 브라우저 로직)

#### [MODIFY] `public/index.html`
- **AI 질문 버튼 추가**: [AI 이상 감지 내역] 제목이나 필터 버튼 옆에 `[🤖 AI에게 질문하기]` 버튼 추가.
- **채팅 모달창 HTML 추가**: 브라우저 기본 팝업을 피하기 위해(규칙 16), 화면 전체를 살짝 덮는 깔끔한 카드형 팝업(모달) 레이아웃 추가. 질문 입력창과 답변 출력 영역 포함.

#### [MODIFY] `public/js/app.js`
- **모달 제어 로직**: 버튼 클릭 시 모달창 열기/닫기 처리.
- **AI 요청 로직**: 
  - 현재 화면에 표시된 '이상 감지 알림' 내용들을 텍스트로 수집하여 문맥(Context)으로 생성.
  - 사용자가 입력한 질문과 함께 클라우드플레어 내부 서버(`/api/ask-ai`)로 전송(fetch).
  - 로딩 애니메이션 추가 및 AI 답변을 받아와 화면에 표시.

### 3.2. 백엔드 (클라우드플레어 서버 로직)

#### [NEW] `functions/api/ask-ai.js`
- 클라우드플레어 Pages 환경에서 자동으로 서버 API로 인식되는 파일.
- **역할**:
  1. 프론트엔드에서 보낸 데이터(문맥 + 질문) 수신.
  2. 클라우드플레어 환경변수(`env.GEMINI_API_KEY`) 안전하게 꺼내기.
  3. 구글 제미나이(Gemini 1.5 Flash) API 엔드포인트로 실제 요청 전달.
  4. 제미나이의 응답을 프론트엔드에 다시 반환.

## 4. 검증 계획 (Verification Plan)
- **로컬 테스트**: 로컬 환경에서 가상의 응답(Mock)을 주거나 로컬 환경변수를 사용해 모달창과 서버 통신이 정상적으로 이루어지는지 UI 점검.
- **보안 점검**: 브라우저 개발자 도구(F12)의 네트워크 탭을 확인하여, 클라이언트에서 제미나이 API 키가 절대 노출되지 않고 오직 `/api/ask-ai`로만 통신하는지 확인.
