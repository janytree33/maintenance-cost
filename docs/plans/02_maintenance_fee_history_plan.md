# 명세서 내역(조회) 기능 구현 계획서

## 1. 목표
제니께서 훌륭하게 업로드해 주신 3~7월(1403호, 2001호) 데이터들을 활용하여, 사용자가 원하는 호수와 월을 필터링해 내역을 조회할 수 있는 '명세서 내역' 화면을 구축합니다.

## 2. 화면 이동 구조 (SPA 방식)
- 사이드바의 **[대시보드]**와 **[명세서 내역]** 버튼을 누를 때마다, 페이지 새로고침 없이 부드럽게 오른쪽 메인 화면 내용만 교체되도록(Single Page Application) 자바스크립트로 구성합니다.

## 3. UI/UX 디자인 (제니트리 v5.0 기준)
- **필터 영역 (검색 조건)**: 화면 상단에 하얀색 카드(`jt-card`)를 두고, 두 개의 콤보박스(Select)를 배치합니다.
  - 호수 선택: `전체` / `1403호` / `2001호`
  - 월별 선택: `전체` / `2026년 03월` ~ `07월`
- **목록 테이블**: 필터 아래에 표(`jt-table`)를 두어 데이터를 나열합니다.
  - 컬럼: `청구 연월`, `호수`, `총 청구 금액`, `상세 보기`
- **상세 보기 모달**: 표에서 특정 행의 [상세 보기] 버튼을 누르면, 내부 모달이 떠서 해당 월의 세부 항목(건물관리용역비, 수도개별 등)을 모두 보여줍니다.

## 4. 데이터 연동 로직 (Supabase)
- 화면에 들어올 때 Supabase의 `maintenance_fees` 테이블에서 전체 데이터를 한 번에 불러옵니다.
- 총 청구 금액은 DB에 저장된 `fee_items`(세부 항목 JSON) 데이터를 자바스크립트가 자동으로 더해서 계산해 줍니다.
- 사용자가 필터(호수/월)를 바꿀 때마다 화면의 표가 실시간으로 걸러져서 보이도록(Filtering) 처리합니다.

## 5. 진행 단계
1. **화면 뼈대 추가**: `index.html`에 명세서 내역용 화면 구조와 필터, 상세 모달 UI 추가.
2. **화면 전환 로직**: `app.js`에 사이드바 클릭 시 화면이 바뀌는 기능 작성.
3. **DB 조회 및 표 그리기**: Supabase에서 데이터를 가져와서 표에 예쁘게 그리는 기능 작성.
4. **필터링 및 상세 보기**: 호수/월별 검색 기능과 모달 띄우기 로직 완성.
